# epdesk.github.io

The EPDesk website, served by GitHub Pages at https://epdesk.github.io/

- `/` Norwegian landing page, `/en/` English
- `/pilot/` the customer pilot: upload any file, get a sample EPD pack built from 13 real EPDs
- `/film/` the demo film, served from the separate `epdesk/film` repository

This repository holds built files only. They are generated by `golive.sh` in the private
`epdesk-site` repository; edit the source there and rebuild rather than editing these files.
